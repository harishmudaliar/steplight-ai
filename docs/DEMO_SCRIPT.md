# Evidence-Bounded Demo Script

**Use only a configured local development environment. Do not use the smoke installer as a production-connected demo.**

1. State the goal: one manageable action, with no guilt, streaks, or forced timer.
2. Sign in to a prepared local demo account and open task creation.
3. Create one task and choose **Low** capacity. Show one generated suggestion and its stated source.
4. Select **Can’t** and show the smaller local alternative. Explain that the 15-second action is deterministic local behavior, not an AI-generated claim.
5. Select **Rest**, return later, and resume the saved task/step.
6. Demonstrate **Change** by editing task wording or capacity, and **Dismiss** without marking work complete.
7. Select **Done** to complete the step, then show the next-step flow and saved history.
8. Open “What the AI Sees” and explain default-off Gemini consent and exact data categories. State that live provider generation is currently unverified.
9. If showing both clients, use the same deployed backend only after it is available. A screenshot or local build alone is not evidence of cross-device sync.
10. Close with the limits: no Smart Focus blocking, no production deployment, and no claim of clinical advice.

Do not use the `api.example.test` packaged installer for account/task demonstrations; it is a build-only placeholder.
