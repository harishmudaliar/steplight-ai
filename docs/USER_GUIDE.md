# Steplight AI — User Guide

Steplight offers one small next action at a time. It is a task-support tool, not a diagnostic or treatment service.

## Start a task

1. Sign in or create an account.
2. Choose **Tasks** and enter one task in your own words.
3. Pick current capacity: **Low**, **Medium**, or **High**. Capacity can be changed later.
4. Review the single suggested step and its “Why this step?” explanation.
5. Choose an action that fits:
   - **Done** records that step and returns to the task for the next suggestion. It does not automatically complete the whole task.
   - **Can’t** sets the rejected step aside and offers a smaller local alternative. It is okay to choose this again.
   - **Rest** pauses the task and saves the unfinished step so it can be resumed later.
   - **Change** sets aside the current suggestion and lets you edit the task or capacity before trying again.
   - **Dismiss** closes the suggestion without marking it done.

## History and privacy

- Progress and history reflect saved task/step events, not streaks or scores.
- In Settings, review AI personalization consent, export your account data, or request account deletion with password confirmation.
- Gemini personalization is off by default. If enabled, the app discloses that task title, optional notes/context, capacity, preferred duration, and retrieved strategy candidates may be sent to Google. Email, password, auth tokens, and database credentials are not sent by the backend prompt flow.
- Offline mode does not queue writes. Reconnect and reload before editing. A stale edit may be rejected so you can reload the latest version.
- App/site blocking is not implemented. Windows notifications are opt-in and may be suppressed by Windows settings.

## Desktop

The Windows app uses the same task interface as the website. `Ctrl+Shift+C` toggles compact mode. Window size and compact preference are saved locally. Notifications, if supported and enabled, are limited to a generic step-completion message.

## Getting help

Use the Help and Privacy screens for product information. Steplight does not replace professional or emergency support.
